一、校招简历的结构（不会错）

  1. 基本信息：姓名、电话、邮箱、所在城市、求职意向。别写身高体重。
  2. 教育背景：学校、专业、学历、时间；GPA 高就写，低就不写；相关课程挑 3–5 门写。
  3. 实习/项目经历：没有实习就写课程设计、比赛项目、个人博客/小程序。
  4. 校园经历：学生会、社团、志愿活动，写"组织/协调/执行"的能力。
  5. 技能/证书：英语四六级、计算机二级、Python/Office/设计工具。

二、没有实习经历，项目怎么写？

应届生最容易卡住这里。其实课程设计、毕设、GitHub 项目、 even 课程大作业都可以写，关键是写出结果：

❌ 反面："做了一个电商网站的前端页面。"
✅ 正面："独立完成电商前台前端（Vue3 + Element Plus），实现商品列表、购物车、订单流程；首屏加载优化后 LCP 从 2.8s 降至 1.2s。"

公式：用了什么技术 + 完成了什么功能 + 取得了什么结果（数字最好）。

三、STAR 法则在校招简历里的写法

  • S 情境：课程要求/比赛任务是什么
  • T 任务：你在小组里负责什么
  • A 行动：具体做了什么
  • R 结果：获得成绩/提升效率/获奖
示例："全国大学生数学建模比赛（S），负责数据清洗与模型可视化（T），用 Python pandas + matplotlib 处理 10 万条数据并搭建可视化看板（A），团队获省级二等奖（R）。"

四、校招简历避坑

  • 🚫 一份简历海投所有岗位——按岗位 JD 调关键词。
  • 🚫 写"熟练使用 Office"——太水，改成"Excel 数据透视表处理 5000+ 条数据"。
  • 🚫 自我评价写"性格开朗、吃苦耐劳"——换成"3 个月自学 Python 并完成数据分析项目"。
  • ✅ 文件名：姓名-岗位-学校-应届.pdf
