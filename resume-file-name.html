简历文件命名：最后一公里的细节

HR 下载几十份简历后，文件名决定了 TA 能不能快速找到你。『姓名-岗位-简历』是通用标准，乱命名等于主动增加被漏看的概率。

一、标准命名

张三-前端开发-简历.pdf
李四-产品经理-简历.pdf

二、投递邮件时

  • 附件名 = 正文提到的名字，保持一致
  • 岗位名和邮件标题里的岗位一致

三、避坑清单

🚫 简历.pdf（几十个重名，HR 分不清）
🚫 新建 Microsoft Word 文档.pdf
🚫 张三的简历最终版最终版2.pdf
🚫 中文标点/空格乱入导致乱码

四、进阶

如果岗位要求带编号（如"应聘编号 A12"），把编号写进文件名：『张三-A12-前端开发-简历.pdf』，方便 HR 和系统归档。
